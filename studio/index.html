業種別スタジオ（見本）

仕事の流れを、ひとつの画面でつなげた見本です。実際に入力して動かせます。

建設スタジオ

見積 → 現場と工程表 → 日報・出面 → 請求 → 入金。原価と粗利は日報から自動で。

車屋・バイク屋スタジオ

車検の案内 → ピット予約 → 整備見積 → 請求 → 入金。部品在庫と中古車の粗利も。

経理・事務スタジオ

明細の取り込みと仕訳 → 請求書 → 入金の照合 → 勤怠 → 月次まとめ。

表示されているデータは架空の見本です。入力した内容はお使いのブラウザの中だけに保存され、外部には送信されません。税の扱いなどの最終確認は、国税庁の案内や専門家にご確認ください。
