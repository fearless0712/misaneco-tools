小さな士業事務所の事務を楽にする入り口

この記事には広告（アフィリエイトリンク）を含みます。

社労士、行政書士、税理士の事務所。先生の仕事を支える事務スタッフは、毎日たくさんの細かい作業をしています。書類の受け取り、期限の確認、日程の調整、お客さまへの連絡、請求と入金の確認。どれも大事で、もれが許されない仕事です。

この記事では、小さな士業事務所の事務を、6つに分けて見ます。それぞれ「何が手間か」「方法」「はじめの一歩」を書きました。

新しいシステムを入れる話ではありません。Excel、Googleスプレッドシート、GAS、Power Automate、定型文など、身近な道具で始められることを中心にしています。全部を一度に変えなくて大丈夫です。まずは1つだけ選んでください。

1. 書類の受け取りと整理

何が手間か 書類が届く方法がばらばらです。郵送、メールの添付、写真、共有フォルダ、手渡し。どのお客さまの、どの書類が、どこにあるのか。探すだけで時間がかかります。

方法 - お客さまごとのフォルダを作り、中に年度や手続きごとのフォルダを作る - ファイル名のルールを決める（例：「受取日_お客さま名_書類名」） - GASやPower Automateで、決まった件名のメールの添付ファイルを、決めたフォルダへ自動で保存する - 「書類受取台帳」を作る（受取日・お客さま・書類名・受け取り方・保存場所・原本の返却）

はじめの一歩 今日届いた書類から、台帳に1行ずつ書きます。ファイル名のルールも、今日決めて事務所の中で共有しましょう。最初はルールを1つ決めるだけで十分です。

2. 期限の管理

何が手間か 申請、届出、申告、更新。事務所には期限のある仕事がたくさんあります。先生の手帳、カレンダー、付せんと、期限が書かれている場所が分かれていると、見落としがこわいです。

方法 - 期限の一覧表を作る（お客さま・手続き・期限日・準備を始める日・担当・状況） - 期限日が近い行や、状況が「未着手」のままの行に色が付くよう、条件付き書式を設定する - GASやPower Automateで、準備を始める日になったら担当者にメールが届くようにする - 毎年同じ時期に来る手続きは、1年分を先に表に入れておく

期限がいつなのかは、手続きや制度によって違います。具体的な日付は、各制度の公式案内で確認してください。表には「確認した日」と「確認した資料」の列も作っておくと安心です。

はじめの一歩 来月までに期限が来る仕事を、1つの表に書き出します。毎朝、その表を開いて上から見る。これを1週間続けてみましょう。

3. 顧客との日程調整

何が手間か 面談や打ち合わせの日程を決めるのに、何往復もメールや電話をします。先生の予定と、お客さまの予定と、会議室の空き。合わせるのが大変です。

方法 - 先生の予定を共有カレンダーにまとめ、事務スタッフも見られるようにする - 日程の候補を出すメールを定型文にする（候補日時を3つ、場所、所要時間、持ち物） - Googleフォームで「希望日時」を選んでもらい、回答をスプレッドシートで受け取る - 決まった予定の前日に、確認のメールを送る定型文を用意する

はじめの一歩 日程調整のメールを1通、定型文として保存します。次からは、その定型文の日時だけを書きかえて送ります。

4. 定型メール

何が手間か 書類のお願い、受け取りのお礼、手続き完了のお知らせ、請求のご案内。同じような内容を、毎回ゼロから書いています。人によって言い回しが違うのも気になります。

方法 - よく送るメールを場面ごとに書き出し、定型文の一覧を作る - 定型文の中に、お客さま名や日付を入れる場所を「〇〇」のように決めておく - メールソフトの署名やテンプレート機能に、定型文を登録する - スプレッドシートの一覧から、GASで宛先ごとに名前を差し込んだ下書きを作る

送る前には、宛先と添付ファイルを必ず目で確認してください。士業事務所は大事な個人情報を扱います。自動で「送信」まではしないで、「下書き」までにしておくと安心です。

はじめの一歩 先週送ったメールの中から、よく似た内容のものを3つ選び、定型文にします。事務所のみんなで同じ定型文を使えば、言い回しもそろいます。

5. 請求

何が手間か 顧問料のように毎月同じ金額の請求と、手続きごとの請求が混ざっています。請求書を作り忘れたり、同じ請求を二度出したりしないか心配です。

方法 - 「請求予定表」を作る（お客さま・請求の種類・金額・請求日・請求書番号・送付済み） - 毎月の顧問料は、月ごとの行をまとめて作っておく - 請求書のひな形をExcelで1つにし、請求予定表の行を選ぶと内容が入るようにする（検索の関数を使います） - 請求書番号のルールを決める（例：年月＋連番）

請求書に何を書くかは、税の制度で決まっている部分があります。書き方は国税庁などの公式案内や、事務所の先生に確認してください。

はじめの一歩 今月出す請求を、1つの表に書き出します。「送付済み」の列にチェックを入れていくだけで、出し忘れが減ります。

6. 入金の確認

何が手間か 銀行の明細と請求書を、1件ずつ見比べています。振込の名前がお客さまの名前と違うことも多く、確認に時間がかかります。

方法 - 請求予定表に「入金日」と「入金額」の列を足す - 銀行の明細をCSVでダウンロードし、Excelに貼り付けて、金額と名前で照らし合わせる - お客さまごとに、振込で使われる名前を記録しておく - 入金日が空のまま支払期日を過ぎた行に色を付ける - 入金のお願いのメールを、ていねいな定型文にしておく

はじめの一歩 先月分の請求について、入金日を表に書き込みます。空いている行だけを確認すればよくなります。

進め方のコツ

  • 書く場所を1つにする。同じ情報を2か所に書かない
  • 名前の付け方（ファイル名、フォルダ名、番号）を先に決める
  • お客さまの情報を扱う表やフォルダは、見られる人を決めて共有する
  • 自動化は「お知らせ」と「下書き」から始める。送信や削除は人が確認する
  • 1つの業務で1か月使ってみてから、次に進む

自分に合う方法を調べるには

どの方法が自分の事務所に合うか、迷うこともあると思います。「業務の自動化 診断＆推進プラン」（無料）では、自分の業種と業務を選ぶと、方法の比較とおすすめが出ます。まずは気になる業務を1つ選んで、試してみてください。
