工事写真台帳の作り方｜撮るとき・並べるとき・まとめるときのコツ（民間の小さな現場向け）

「写真はたくさん撮ってあるのに、台帳にまとめるのは休みの日」。スマホの中の数百枚から選んで、Excelに貼って、説明を書いて……。現場が終わってからの作業として、いちばん後回しになりやすいものの1つです。

この記事では、民間の小さな現場（塗装・水道・電気・リフォームなど）向けに、写真台帳を早くまとめるための手順をまとめます。

発注者や役所が様式を決めている場合（公共工事など）は、その様式と決まりに従ってください。ここで扱うのは、一般的な写真台帳の形です。

1. 撮るときに決めておくこと

あとで並べやすい写真は、撮るときに決まります。

  • 同じ場所を、同じ向きで撮る：着工前・施工中・完成を同じ角度で撮ると、比べて見せやすくなります。
  • 最初の1枚に「どこか」が分かるものを入れる：建物の全景や、部屋の入口から1枚。
  • 黒板やメモがあれば一緒に写す：工種・場所・日付をその場で残せます。
  • スマホの日付設定を確かめる：撮影日は写真の情報（Exif）に記録されます。日付がずれていると、そのずれたまま残ります。

2. 写真ごとに書くこと

台帳の1枚ごとに、次の5つを書くとまとまります。

項目 例
区分 着工前／施工中／完成
工種 高圧洗浄・下塗り・配管・配線 など
撮影日 2026年10月6日
場所 北面・2階・浴室 など
説明 「既存外壁にチョーキング・細かいひび割れあり」のように、見て分かることを1行

説明は「何をした」より「何が分かる写真か」を書くと、受け取った人に伝わりやすくなります。

3. 並べ方

  • 撮影日の順に並べるのが基本です。
  • 同じ日の中では、区分（着工前→施工中→完成）、次に場所の順にすると読みやすくなります。
  • 写真が多いときは、工種ごとに分けて別の台帳にすると、1冊が重くなりません。

4. A4に何枚並べるか

1ページの枚数 向いている使い方
2枚 写真を大きく見せたい（損傷の箇所、仕上がりの確認）
3枚 いちばん一般的。写真と説明のバランスがよい
6枚 枚数が多い工事の記録。説明は短めに

表紙に、工事名・工事場所・発注者・施工者・工期・写真の枚数・作成日をまとめておくと、あとから探すときに役立ちます。

5. 渡し方

  • 紙で渡すなら、A4縦・倍率100%で印刷します。
  • データで渡すなら、PDFに保存して1つのファイルにまとめます。写真をそのまま何十枚も送るより、受け取る側も見やすくなります。

よくある失敗

  1. iPhoneの写真（HEIC形式）が開けない：パソコンやソフトによっては表示できません。JPEGで保存する設定にしておくか、JPEGに変換してから使います。
  2. 撮影日が全部同じ日になっている：パソコンに取り込んだ日になってしまうことがあります。写真の情報（撮影日時）で確かめます。
  3. 同じような写真が続いて、どれがどこか分からない：場所と説明を必ず書きます。

チェックリスト

  • ☐ 着工前・施工中・完成を、同じ角度で撮った
  • ☐ スマホの日付設定が正しい
  • ☐ 写真ごとに区分・工種・撮影日・場所・説明を書いた
  • ☐ 撮影日の順に並べた
  • ☐ 表紙に工事名・場所・工期・枚数を入れた
  • ☐ PDFにまとめて渡せる形にした
  • ☐ 発注者の様式の指定がないか確かめた
