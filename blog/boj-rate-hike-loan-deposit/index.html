日銀の利上げ（政策金利1.25%）で、住宅ローン・事業の借入れ・預金・投資はどう変わる？｜影響とメリット、今やる確認リスト

「日銀が利上げ」というニュースを見て、「自分のローンはどうなるの？」と思った人は多いと思います。

この記事では、日本銀行や銀行が出している資料をもとに、何が決まったのかと、住宅ローン・事業の借入れ・預金・投資にどう関係するのかを、やさしい言葉でまとめます。最後に、今のうちにやっておきたい確認リストも載せています。

※この記事は一般的な説明です。特定の金融商品の売り買いや、借り換えをすすめるものではありません。

何が起きたのか

日本銀行は、2026年9月17日〜18日の金融政策決定会合で、次のことを決めました（日本銀行「金融市場調節方針の変更について」2026年9月18日）。

  • 政策金利（無担保コールレート・オーバーナイト物）を、1.0%程度 → 1.25%程度に引き上げ
  • 新しい方針は、9月24日から適用
  • 採決は、賛成7・反対2

日本銀行は同じ公表文で、物価の上がり方が2%に近づいていることなどを理由にあげています。そして、今後も経済や物価の様子に応じて「引き続き政策金利を引き上げ」ていく考えを示しています。

銀行の金利も動き始めています

政策金利が上がると、銀行の金利も動きます。たとえば三菱UFJ銀行は、9月18日に次の変更を発表しました。

金利 変更前 変更後 改定日
短期プライムレート 2.375% 2.625% 2026年11月2日
円普通預金金利 0.40% 0.50% 2026年11月2日

ここで大事なのは、貸す金利（短期プライムレート）は＋0.25%、普通預金の金利は＋0.10%と、上がり方が同じではないことです。どれだけ上がるかは、銀行や商品によって違います。

変動金利の住宅ローンへの影響

しくみ：多くは「短期プライムレート」に連動

変動金利の住宅ローンは、多くの銀行で、短期プライムレートなどを基準に金利が決まります。全国銀行協会の説明では、変動金利は「通常半年ごとに見直されます」。

ただし、見直しの回数は銀行や契約によって違います。たとえば三菱UFJ銀行では、2025年4月1日以降に借りた変動金利は「毎月1日を基準日」に見直すと案内しています。それより前の契約は、金利の種類によって違います。

自分のローンが「いつ見直されて、いつの返済から変わるか」は、契約書や「返済予定表」「ご返済のお知らせ」で確かめましょう。

どれくらい増える？（計算の例）

元利均等返済（毎月の返済額が同じ）で計算しました。式はExcelの PMT 関数と同じです。

例：残り3,000万円・残り30年

金利 毎月の返済額 今より増える額（月） 年にすると
0.5%（今） 89,757円 ― ―
0.75%（＋0.25%） 93,086円 ＋3,329円 ＋39,948円
1.0%（＋0.5%） 96,492円 ＋6,735円 ＋80,820円
1.5%（＋1.0%） 103,536円 ＋13,779円 ＋165,348円

0.5%から1.0%になると、30年間で払う利息の合計は、約231万円 → 約474万円になります。

これは「金利がすぐに上がって、そのあとずっと同じ」とした場合の計算です。実際の金利の動きは、だれにもわかりません。

「5年ルール」「125%ルール」とは

多くの銀行の変動金利（元利均等返済）には、次の2つのルールがあります。

  • 5年ルール：金利が変わっても、毎月の返済額は5年間変わらない
  • 125%ルール：5年ごとに返済額を見直すとき、増えるのは前の返済額の1.25倍まで

「それなら安心」と思うかもしれませんが、注意があります。

  1. 返済額は同じでも、中身が変わります。 返済額のうち利息の割合が増え、元金の減りが遅くなります。上の例（0.5%→1.0%）では、1回目の利息が 12,500円 → 25,000円 になり、返済額に占める利息の割合は 約14% → 約28% になります。
  2. 未払い利息が出ることがあります。 金利が大きく上がって、毎月の利息が返済額より多くなると、払いきれない利息（未払利息）がたまっていきます（全国銀行協会）。
  3. 増えた分がなくなるわけではありません。 後に回るだけです。

また、このルールを使っていない銀行もあります。 たとえばソニー銀行は、「5年ルール」「125%ルール」に基づく返済額の計算をしておらず、金利の見直しのたびに返済額を変えると説明しています。元金均等返済には、このルールがないのが一般的です（三菱UFJ銀行の案内でも「元金均等返済の場合は5年ルール・125%ルールはありません」）。

自分の契約にこのルールがあるかどうかは、契約書で確認してください。

固定金利の住宅ローン

  • 全期間固定：借りたときの金利のままです。今回の利上げで、今の返済額は変わりません。
  • 当初だけ固定（10年固定など）：固定の期間が終わったとき、その時点の金利で次の金利が決まります。固定期間がいつ終わるかを確かめておきましょう。
  • これから借りる人の固定金利は、政策金利よりも、長い期間の金利（長期金利）の動きの影響を受けやすいと言われています。

事業の借入れ（運転資金など）

お店や会社の借入れも、短期プライムレートなどに連動する「変動金利」のことがあります。

例：残り500万円・5年・元利均等で、2.0% → 2.5%

  • 毎月の返済額：87,639円 → 88,737円（月 1,098円増）
  • 5年間の利息の合計：258,328円 → 324,208円

1本だけなら小さく見えても、借入れが何本もあると合計は大きくなります。今のうちに、次のことをやっておくと安心です。

  • 借入れごとに「固定か変動か」「基準になる金利」「見直しの日」を一覧にする
  • 資金繰り表の返済・利息の行を、金利が＋0.25%・＋0.5%になった場合で作り直してみる
  • 返済の条件は契約によって違うので、わからないところは借入先の金融機関に聞く

預金のメリット

金利が上がると、預金の利息が増えることがあります。これは利上げの「メリット」です。

ただし、上で見たとおり、普通預金の金利は政策金利と同じだけ上がるとは限りません。 定期預金の金利の上がり方も、銀行や期間によって違います。

例：預金300万円、金利0.2% → 0.3% の場合（1年分）

  • 利息（税引き前）：6,000円 → 9,000円
  • 税引き後の目安：4,782円 → 7,172円（年 2,390円増）

預金の利子には、20.315%（所得税・復興特別所得税15.315%＋住民税5%）の税金がかかり、受け取るときに差し引かれます（国税庁「No.1310 利息を受け取ったとき（利子所得）」）。

債券・株・為替への一般的な影響

ここは「一般的にこう言われることが多い」という話です。実際の値動きは、ほかのたくさんの理由でも動くので、決めつけないでください。

  • 債券：金利が上がると、すでに出ている債券の価格は下がりやすい、と一般に説明されます。これから買う債券は、利回りが高くなることがあります。
  • 株：借入れの多い会社には利息の負担が増える一方、銀行などには利ざやが増える面がある、と言われます。ただ、株価は景気・会社の業績・海外の動きなどでも大きく動きます。
  • 為替（円とドルなど）：日本の金利が上がると円が買われやすい、と言われることがあります。しかし、為替はアメリカなどの金利や世界の動きにも強く左右されます。

投資の判断は、ご自分の状況に合わせて、必要なら専門家に相談してください。

10月29日〜30日の会合で見ておくこと

次の金融政策決定会合は、2026年10月29日（木）〜30日（金）です。30日には「経済・物価情勢の展望（展望レポート）」の基本的見解も公表される予定です（日本銀行の会合日程）。

結果はまだ出ていません。民間の予想では、たとえば第一生命経済研究所のレポート（10月7日）が、10月は利上げを見送り、12月の会合で利上げと予想しています。これはあくまで予想です。

会合の日に見ておくとよいのは、次の3つです。

  1. 政策金利を変えたか、据え置いたか
  2. 公表文で、これからの利上げについてどう書いているか
  3. そのあと、自分の銀行が短期プライムレートや預金金利を変えると発表するか

今やる確認リスト

  • ☐ 住宅ローンが「変動」「固定」「当初だけ固定」のどれかを確かめた
  • ☐ 変動なら、金利の見直しの時期と、返済額がいつから変わるかを確かめた
  • ☐ 5年ルール・125%ルールがある契約かを、契約書で確かめた
  • ☐ ＋0.25%・＋0.5%・＋1.0%のときの返済額を計算してみた
  • ☐ 事業の借入れを一覧にして、資金繰り表の返済の行を見直した
  • ☐ 預金の金利を、自分の銀行の案内で確かめた（普通預金・定期預金）
  • ☐ 10月30日の会合の結果と、そのあとの銀行の発表を見る
  • ☐ 借り換え・繰上げ返済を考えるなら、金融機関や専門家に相談する

返済がいくら増えるか、自分の数字で計算する
