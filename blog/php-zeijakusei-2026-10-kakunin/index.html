PHPの重大な脆弱性（2026年10月）｜自分のサイトは大丈夫？ 確認と更新の手順

2026年10月21日、PHPの開発チームが、外部から勝手にコードを実行されるおそれのある脆弱性2件を修正したバージョンを公開しました。 PHPは、WordPressをはじめ多くのWebサイトや業務システムの裏側で動いています。会社や個人のサイトをPHPで動かしている場合は、今すぐバージョンを確かめて、修正版に更新してください。

この記事でわかること：

  • 何が起きたのか（公式の発表の要点）
  • 修正版の番号
  • 自分のサイトのPHPのバージョンを確かめる方法
  • すぐに更新できないときの注意

何が起きたのか

PHP公式の発表によると、修正された脆弱性は次の2件です。

  • CVE-2026-109618：メモリが足りなくなったときの処理の途中で、中途半端なデータを正しいものとして扱ってしまう問題
  • CVE-2026-109619：前のリクエストの内部の情報が、解放されたあとも残り、次のリクエストで使われてしまう問題

どちらも深刻度（CVSS v4.0）は 9.2 で、ログインしていない外部の人から、任意のコードを実行されるおそれがあるとされています。

公式の発表では、Webのリクエストを処理しているPHPはすべて対象とされています。たとえば、PHP-FPM、Apacheのmod_php、php-cgi、FrankenPHP、LiteSpeed です。とくにmod_phpは、アプリのコードが動く前に攻撃が成り立つ例が示されていて、危険度がいちばん高いとされています。

10/22追記： IPA（情報処理推進機構）も2026年10月22日に注意喚起を出しました（この2件は「PHP2Shell」と呼ばれています）。IPAは、修正版への更新に加えて、すぐ更新できない場合の暫定対策やアクセス制限、それも難しい場合は外部からのアクセスを止めることも検討するよう呼びかけています。

修正版の番号

次のバージョン以上に更新します。

  • PHP 8.5 系：8.5.12
  • PHP 8.4 系：8.4.27
  • PHP 8.3 系：8.3.36
  • PHP 8.2 系：8.2.35（8.2系のサポートは2026年12月31日まで）

PHP 8.1以前は、公式の更新がもう出ません。公式はGitHubで最小限の修正（7.4・8.0・8.1向け）を公開していますが、できるだけ新しいバージョンへの移行を検討してください。

自分のサイトのPHPのバージョンを確かめる

WordPressの場合

管理画面の「ツール」→「サイトヘルス」→「情報」タブ →「サーバー」を開くと、PHPのバージョンが表示されます。

レンタルサーバーの場合

多くのレンタルサーバーでは、管理画面（コントロールパネル）の「PHPのバージョン設定」のような画面で、使っているバージョンを確かめたり、切り替えたりできます。共用のレンタルサーバーでは、サーバー会社が修正版への更新を進めていることがあります。お使いのサーバー会社のお知らせを確認してください。メンテナンスでサイトや管理画面が一時的に止まることもあります。

自分でサーバーを管理している場合

コマンドで php -v を実行すると、バージョンが表示されます。WebサーバーとコマンドラインのPHPが別のバージョンになっていることもあるので、Webで動いているPHPも確かめてください。※バージョン確認のために phpinfo() のページを作った場合は、確認後すぐに消してください。サーバーの情報が外から見えてしまいます。

制作会社に任せている場合

「PHPの今回の脆弱性（CVE-2026-109618／109619）への対応状況と、今のPHPのバージョン」を、制作会社や保守の担当者に問い合わせてください。

すぐに更新できないときの注意

公式の発表では、完全な対策は更新だけとされています。

更新までのあいだ、php.iniなどの設定で一部の攻撃の経路を減らす方法も示されていますが（例：session.upload_progress.enabled=0 にして全ワーカーを再起動する）、これだけでは安全になりません。設定を変えたうえで、できるだけ早く更新してください。

確認のチェックリスト

  • ☐ 自分のサイト・システムがPHPで動いているか確かめた
  • ☐ PHPのバージョンを確かめた
  • ☐ 修正版（8.5.12／8.4.27／8.3.36／8.2.35 以上）に更新した、または更新の予定を決めた
  • ☐ レンタルサーバーなら、サーバー会社のお知らせを確認した
  • ☐ 制作会社に任せているなら、対応状況を問い合わせた
  • ☐ 確認用に作った phpinfo のページを消した
