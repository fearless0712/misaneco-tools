A simple monthly expense tracker in Google Sheets or Excel (with SUMIFS totals)

If you work for yourself, receipts pile up fast. A coffee with a client, a software subscription, a train ticket, a new keyboard. At the end of the month, or the end of the year, someone has to add them all up. Usually that someone is you.

You do not need accounting software to stay on top of it. One sheet with a few columns and one formula can show you what you spent, on what, and in which month.

This guide shows you how to build a simple expense tracker in Google Sheets or Excel. Everything works in both apps unless noted. It takes about 15 minutes.

What you will build

  • An Expenses tab with one row per receipt.
  • A dropdown for categories, so the same thing is always spelled the same way.
  • A helper column that turns each date into a month, like 2026-03.
  • A Summary tab that shows totals by category and month with SUMIFS.
  • A quick check for receipts you have logged but not saved.

Step 1. Set up the columns

Create a tab called Expenses and add these headers in row 1:

A B C D E F G H I
Date Vendor Description Category Amount Paid with Receipt saved? Month Notes

Tips:

  • Column A must be a real date. Format it as a date.
  • Column E must be a plain number. Do not type a currency sign as text. Use number or currency format instead.
  • For a refund, enter a negative amount. The totals will handle it.
  • Paid with is useful later: card, cash, bank transfer, or which card.

Step 2. Add a category dropdown

Typos break totals. "Software", "software " and "Sofware" are three different things to a formula. A dropdown fixes that.

First, make a list. Create a tab called Lists and type your categories in A2 down, with a header "Category" in A1. For example:

  • Software and subscriptions
  • Equipment
  • Office supplies
  • Phone and internet
  • Travel
  • Meals
  • Advertising
  • Professional fees
  • Bank fees
  • Other

Pick categories that match how you, your bookkeeper or your tax return group things. That makes year-end much easier. Keep the list short. Ten to fifteen is plenty.

Then add the dropdown:

Google Sheets: select D2:D2000 on the Expenses tab. Choose Data > Data validation > Add rule. Under criteria, choose Dropdown (from a range) and enter Lists!A2:A20.

Excel: select D2:D2000. Choose Data > Data Validation. Under Allow, choose List. In Source, enter =Lists!$A$2:$A$20.

Do the same for column G (Receipt saved?) with a simple list: Y, N. You can type that directly into the dropdown options instead of using a range.

Step 3. Add the Month helper column

In H2, paste:

=IF(A2="","",TEXT(A2,"yyyy-mm"))

Copy it down as far as you expect to go, for example to row 2000.

What it does:

  1. Shows nothing if there is no date yet, so empty rows stay clean.
  2. Otherwise turns the date into text like 2026-03.

Why text? Because a month label like "2026-03" is easy to match in SUMIFS, sorts in the right order, and reads clearly.

One note for Excel: if your Excel is set to a language other than English, the date codes in TEXT may be different (for example, some languages use other letters for year). If H2 shows the wrong result, check the format codes for your language.

Step 4. Build the summary with SUMIFS

Create a tab called Summary.

  1. In A3 down, list your categories. You can copy them from the Lists tab.
  2. In B2 across, type the months you want to see: 2026-01, 2026-02, 2026-03 and so on.

Important: type each month with an apostrophe in front, like '2026-01. Without it, both Excel and Google Sheets may turn it into a date, and then it will not match the text in column H. The apostrophe does not show in the cell.

Now in B3, paste:

=SUMIFS(Expenses!$E$2:$E$2000,Expenses!$D$2:$D$2000,$A3,Expenses!$H$2:$H$2000,B$2)

Copy it across and down to fill the whole table.

How to read it: add up the amounts in column E, but only where the category matches the name in column A of this row, and the month matches the label in row 2 of this column.

The $ signs matter. $A3 keeps the category column fixed when you copy across. B$2 keeps the month row fixed when you copy down.

Then add totals:

  • At the end of each row, a category total for the whole period: =SUM(B3:M3) if your months run from B to M.
  • Under each month, a monthly total: =SUM(B3:B12) if your categories are in rows 3 to 12.

Step 5. Check nothing is missing

Two quick checks keep the numbers honest. Put them anywhere on the Summary tab, with a label next to each.

Every expense has a category. This counts rows with an amount but no category:

=COUNTIFS(Expenses!E2:E2000,"<>",Expenses!D2:D2000,"")

If it is not 0, some rows are missing from your summary table. You can also compare =SUM(Expenses!E2:E2000) with the grand total of your summary. They should be the same.

Every expense has a receipt. This counts logged expenses where Receipt saved? is not Y. Blank counts as missing, on purpose:

=COUNTIFS(Expenses!A2:A2000,"<>",Expenses!G2:G2000,"<>Y")

And this shows how much money those rows add up to:

=SUMIFS(Expenses!E2:E2000,Expenses!A2:A2000,"<>",Expenses!G2:G2000,"<>Y")

To see missing receipts per month, put this under the month labels and copy across:

=COUNTIFS(Expenses!$H$2:$H$2000,B$2,Expenses!$G$2:$G$2000,"<>Y")

To find the rows themselves, turn on a filter on the Expenses tab and show only N and blanks in column G.

Name your receipt files the same way every time

Logging a receipt is half the job. The other half is being able to find the file later.

Pick one naming pattern and stick to it:

YYYY-MM-DD_vendor_amount

For example: 2026-03-03_dell_189.00.pdf or 2026-01-05_adobe_22.99.jpg.

Why this works:

  • Files sort by date on their own, in any folder.
  • You can search for a vendor name and find every receipt from them.
  • The amount helps you match a file to a row in your sheet.

Keep one folder per year, with one folder per month inside it if you get a lot of receipts. When you save a file, set Receipt saved? to Y in the sheet. That is what makes the missing-receipt check work.

How long should you keep receipts?

It depends on your country and your situation. The rules are different in the US, UK, Canada and Australia, and can change. Do not guess.

Using it day to day

  • When you pay for something: add a row, pick a category, and save the receipt with the naming pattern. It takes a minute.
  • Once a week: check the missing-receipt count. Chase any receipts while you still remember where they are.
  • Once a month: add the new month label to the Summary tab and look at the totals. Is anything bigger than you expected?
  • At year-end: the Summary tab already has your totals by category. Hand it to your bookkeeper with the receipt folder.

The key habit is simple: one row and one saved file for every receipt, on the day you get it.
