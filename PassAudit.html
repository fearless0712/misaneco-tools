パスワードの一覧（CSV）を入れる

ここにCSVファイルをドラッグ、またはクリックして選ぶ
Chrome・Edge・Firefox・Safari・1Password・Bitwarden などで書き出したCSV
⚠ 書き出したCSVには、すべてのパスワードがそのまま入っています。調べ終わったら、CSVファイルはすぐに削除し、ゴミ箱も空にしてください。メールやチャットで送ったり、クラウドに置いたりしないでください。
パスワードは画面に表示しません（最初と最後の1文字だけ）。直す順番：①使い回し ②弱い ③似ている。お金・メール・仕事のアカウントから先に直しましょう。

直し方

  1. 大事なアカウントから変える。メール・銀行・クレジットカード・仕事・SNSの順がおすすめです。特にメールは、ほかのサービスのパスワード再設定に使われるので最優先です。
  2. サイトごとに別のパスワードにする。パスワード管理アプリ（ブラウザの保存機能でも可）の「パスワードを生成」で、長くてランダムなものを作ります。覚える必要はありません。
  3. 二段階認証（2要素認証）をオンにする。パスワードが漏れても、すぐには入られにくくなります。使えるサービスでは「パスキー」も便利です。
  4. 書き出したCSVを削除する。ゴミ箱も空にします。

How to fix

  1. Start with important accounts: email first (it can reset everything else), then banking, cards, work and social.
  2. Use a different password for every site. Let your password manager (or browser) generate long random ones — you don't need to remember them.
  3. Turn on two-factor authentication, or use passkeys where available.
  4. Delete the exported CSV and empty the trash.

使い方

  1. このファイル（PassAudit.html）を、ブラウザで開きます。インターネットは不要です。
  2. パスワードの一覧をCSVで書き出します（下の「書き出し方」）。
  3. CSVを入れると、使い回し・弱い・似ているパスワードを一覧にします。
  4. 直し終わったら、CSVファイルを削除してください。

CSVの書き出し方（例）

  • Chrome：設定 →「自動入力とパスワード」→「Google パスワード マネージャー」→「設定」→「パスワードをエクスポート」
  • Edge：設定 →「パスワード」→ 右上の「…」→「パスワードのエクスポート」
  • そのほか（Firefox・Safari・パスワード管理アプリ）も、設定の中に「エクスポート」「書き出し」があります。メニューの名前は版によって違います。

調べること

  • 使い回し：同じパスワードを2つ以上のサイトで使っている
  • 弱い：短い（10文字未満）、数字だけ、よく使われるパスワード、キーボードの並び、くり返し、ユーザー名やサイト名が入っている
  • 似ている：末尾の数字や記号だけを変えたパスワード（例：Neko2023! と Neko2024!）

パスワードは、このパソコンのブラウザの中だけで調べます。通信できない設定で作っているので、外部に送信されることはありません。漏洩したパスワードのデータベースとの照合（インターネットが必要）は行いません。

How to use

  1. Open PassAudit.html in your browser. No internet needed.
  2. Export your saved passwords as CSV (Chrome: Settings → Autofill and passwords → Google Password Manager → Settings → Export; Edge: Settings → Passwords → … → Export).
  3. Drop the CSV here. You'll see reused, weak and similar passwords.
  4. When you're done, delete the CSV file and empty the trash.

Everything runs inside your browser; network access is blocked. It does not check breach databases (that would need the internet).
